LabCas Workflows Documentation
==============================

LabCas Workflows is a framework to define, manage, and execute data processing workflows.


LabCas Workflows is a sub-component of the LabCas data management system and integrates tightly with other LabCas components:
- The LabCas UI can be used to trigger a predefined workflow.
- The LabCas backend services (backend API and Solr database) can be updated by a workflow.

In this documentation, you will find information about installing, configuring, and using LabCas Workflows.
